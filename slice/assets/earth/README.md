# Карты Земли

Источник: Video Copilot, `Earth_Textures_6K.zip` — бесплатная загрузка со страницы плагина ORB
(videocopilot.net/orb). Файлы взяты как есть, без пережатия, 6000 × 3000:

- `day.jpg` — Earth_Diffuse_6K, дневная сторона
- `night.jpg` — Earth_Illumination_6K, огни городов
- `clouds.jpg` — Earth_Clouds_6K, облака
- `gloss.jpg` — Earth_Glossiness_6K, маска воды для солнечного блика
- `normal.jpg` — Earth_NormalNRM_6K, рельеф

Условия коммерческого использования на странице не указаны; карты, судя по всему, сделаны из снимков
NASA (общественное достояние). Перед выпуском игры — уточнить или заменить оригиналами NASA Visible Earth.
Исходный архив — вне репозитория, в `ART/earth/raw`.
